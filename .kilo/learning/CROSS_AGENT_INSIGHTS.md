# Cross-Agent Insights

> Conocimiento transversal gestionado por el orquestador.
> Lecciones aprendidas que son aplicables a múltiples agentes.
> El auditor revisa periódicamente que estas lecciones se están aplicando.

## Formato de Entrada

```markdown
## [YYYY-MM-DD] Título de la lección transversal

- **Origen**: {agente que descubrió la lección}
- **Contexto**: situación que motivó el aprendizaje
- **Lección**: conocimiento extraído, aplicable a otros agentes
- **Agentes afectados**: {lista de agentes que deberían conocer esta lección}
- **Aplicación**: cómo deben aplicar esta lección los agentes
```
